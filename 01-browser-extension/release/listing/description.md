## Detailed description (paste into the listing)

Turn anything you're reading into clean Markdown — in one click.

Markdrop Clipper converts web content into well-formatted Markdown files, ready for Obsidian, Notion, GitHub, or any notes app.

WHAT IT DOES
• Article mode — extracts just the article (no menus, no ads) and converts it to Markdown
• Full page mode — converts the entire page
• Selection mode — select text on any page and convert only that
• Element picker — hover, click the exact blocks you want (shift-click to add more), then copy or download
• YouTube → transcript — paste any YouTube link in the popup and get the title, channel, description and full transcript as Markdown, with optional [hh:mm:ss] timestamps
• Right-click menus — convert the page, a selection, or copy any image as Markdown
• Keyboard shortcut — Alt+Shift+M converts the current page straight to a .md download

QUALITY MARKDOWN
• Proper ATX headings, GFM tables, task-list checkboxes
• javascript: links stripped, giant data-URI images truncated
• Optional front-matter block (title, source URL, date) on every file
• Sensible .md filenames generated from the page title

PRIVACY FIRST
Everything is converted locally in your browser. No accounts, no tracking, no data collection. The only network requests are the ones you trigger (fetching a YouTube transcript, or an optional self-hosted conversion API you configure yourself).

Part of the Markdrop suite — from Dhiva Labs.
